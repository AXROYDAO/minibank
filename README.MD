Скачали репу, открыли терминал, нажали

```
docker compose up -d
```

и все, теперь по адресу http://localhost:8080/ поднят ваш сервачок.

Чтобы выключить, в этом же терминале набираем

```
docker compose down
```

Чтобы прыгнуть внутрь контейнера
```
# кажется кое кто скопировал ридми и не отредактировал его ╬ Ò﹏Ó
docker exec -it bacyla-php-fpm-1 bash
```
Если не завелось, возможно, контейнер назван иначе(буквально так и есть, у тебя название написано в docker-composer.yaml), чтобы проверить запустите
```
docker ps
```

## Мой злые замечания (๑•̀ㅂ•́)و✧

403 Forbidden: Неверный CSRF-токен — вылетал у меня при попытке добавить запись. CSRF-проверка есть в src/index.php, но токен вообще не добавлен ни в одну POST-форму. Поэтому все добавления, удаления и очистка гарантированно получают 403.

локально разворачивать было сложновато. пришлось сначала руками собрать образ; поднять контейнер; сделать composer install; запустить дамп схемы в бд. Было бы очень круто обьеденить эти команды внутри Makefile в какой нибудь make init. Тогда чтобы локально развернуть это все, понадобиться всего лишь запустить 1 команду

ну и code style местами странный — нету пробелов, кривая табуляция. Попробуй в след проекте использовать линтеры и автоформаттеры чтобы такого больше не пропускать. Для общего развития почитай про PSR — заодно сможешь на собесах про него воду лить

А так в целом, норм. Можно переходить к изучению фреймворка
